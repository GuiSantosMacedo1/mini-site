# 🍁 Mini Site sobre o Canadá

Mini site de 3 páginas sobre o Canadá, desenvolvido com **HTML** e **CSS** como parte da **Atividade 3 – Mini Site em HTML** do Proa 2026 (Professor Denis Neves).

## 📄 Páginas

| Página | Arquivo | Conteúdo |
|---|---|---|
| Home | `index.html` | Apresentação do país, curiosidades e informações gerais |
| Sobre | `sobre.html` | História, características, localização (mapa) e curiosidades |
| Contato | `contato.html` | Formulário de contato com nome, e-mail, assunto, categoria e comentário |

Todas as páginas têm um menu de navegação (`nav`) com links para Home, Sobre e Contato.

## 🧱 Elementos utilizados

- **Estrutura semântica:** `header`, `nav`, `main`, `section`, `footer`
- **Títulos e textos:** `h1`, `h2`, `h3`, `p`, `strong`, `em`
- **Listas e links:** `ul`, `li`, `a`
- **Mídia:** `img` com `alt` descritivo e `iframe` com o mapa do Google Maps
- **Formulário:** `form`, `label`, `input`, `select`, `option`, `textarea`, `button`

## 🎨 Estilização

- CSS separado por página (`style.css`, `sobre.css` e `contato.css`)
- Layout com Flexbox
- Design responsivo com `@media` e `clamp()`

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/GuiSantosMacedo1/mini-site.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd mini-site
   ```
3. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server do VS Code).
